# Squall

Squall is the EXEC SQL coprocessor runtime for the
[RedDragon](https://github.com/avishek-sen-gupta/red-dragon) COBOL interpreter. It runs COBOL
programs with embedded static SQL against Db2 or SQLite, standalone or composed with cicada.

Architecture, layout and tests: [docs/reference/squall/architecture.md](../docs/reference/squall/architecture.md).
