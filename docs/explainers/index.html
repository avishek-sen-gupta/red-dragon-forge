cobble · field dataflow

Algorithm explainers

The techniques cobble's field dataflow is built on, for engineers who have not met them before. Each page states a problem, walks a small COBOL program one statement at a time with the analysis state after each, and ends with the precise rule and where it goes wrong.

Read them in order; each builds on the one before.

  1. Fixpoints and worklists — how an analysis handles loops: apply the rules until nothing changes, and why the visiting order matters for cost but not for the answer.
  2. Gen/kill and reaching definitions — for every read, which writes could have produced the value it sees, and why only a certain overwrite may discard one.
  3. Byte-extent aliasing — fields as byte ranges: how groups, REDEFINES and partial writes alias, and why overlapping is not the same as covering.
  4. Value sets and dynamic calls — resolving CALL WS-PGM statically by tracking the values a field can hold, and the reasons that set may be incomplete.
