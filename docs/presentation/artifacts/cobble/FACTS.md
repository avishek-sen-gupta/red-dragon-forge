## Field-level dataflow (section 3)

- **Across programs** (`dataflow/COSGN00C-user-id-across-calls.txt`): COSGN00C.WS-USER-ID
  (bytes 109:117) → CDEMO-USER-ID (149:157) → crosses both XCTL COMMAREA hand-offs into
  COADM01C.DFHCOMMAREA and COMEN01C.DFHCOMMAREA at bytes 24:32 → each callee's
  CARDDEMO-COMMAREA. 5 landings, 1 hop. Byte-exact offsets in the callee are the claim.
- COMMAREA window resolved: COSGN00C CARDDEMO-COMMAREA[125:285] ↔ callee DFHCOMMAREA[0:160] for
  both XCTLs. `dataflow/aliases.jsonl`.
- **Within a program** (`dataflow/COACTVWC-acct-rid-backward.txt`): the RIDFLD of the account read
  WS-CARD-RID-ACCT-ID (used as RIDFLD in 9200/9300) is fed by CDEMO-ACCT-ID (commarea) at
  9000-READ-ACCT, which is fed by CC-ACCT-ID at 2210-EDIT-ACCOUNT, fed by screen input ACCTSIDI at
  2200-EDIT-MAP-INPUTS, plus the inbound DFHCOMMAREA and literals. i.e. terminal field → edit →
  commarea → RIDFLD, recovered statically.
- Diagram of both: `dataflow/dataflow.html`, `dataflow/dataflow.png`.
- Path sampling on COACTVWC: 87 paths reached 172/172 branch edges (100%) in 0.6s.
  `dataflow/trace-COACTVWC-summary.txt`.
- Fixpoint over COSGN00C, COMEN01C, COADM01C, COACTVWC: 275/287 writes resolved to storage

## Honest limitations observed

- **Incomplete by one member**: the CSD names program COCRDSEC but no source exists; `cobble-build`
  prints "1 FAILURE — THIS GRAPH IS INCOMPLETE". `build-warnings.txt`. The golden reference
  includes this state, so compare still passes.
- **17 PROGRAM nodes are unresolved**: system utilities (IDCAMS, SORT, IEBGENER, IEFBR14,
  IKJEFT1B, DFHCSDUP, SDSF, FTP, CEE3ABD, CEEDAYS), COCRDSEC (no source anywhere), COBDATFT and
  MVSWAIT (assembler, `app/asm/` — COBOL-only analysis), CBSTM03A (exists as
  `app/cbl/CBSTM03A.CBL`, but `cobol_globs = ["*.cbl"]` is case-sensitive and skips it — so really
  30 COBOL members, 29 analysed), and three menu targets whose source sits outside the base corpus:
  COTRTLIC, COTRTUPC (`app/app-transaction-type-db2/cbl/`) and COPAUS0C
  (`app/app-authorization-ims-db2-mq/cbl/`). The 4 variable-named PROGRAM nodes of the
  2026-09-14 capture are gone: dynamic targets are resolved (above).
- **Identifier padding leaks**: CICS_FILE has 15 nodes but only 8 distinct names (e.g. `ACCTDAT`
  and `ACCTDAT ` are separate nodes); BMS_MAP ids carry padded mapset names (`COACTVW .CACTVWA`);
  one BMS_MAP (`CCARD-NEXT-MAPSET.CCARD-NEXT-MAP`) is a variable, not a map. So "18 maps" and
  "15 files" overstate; the corpus has 17 mapsets.
- **viz console scripts missing from the venv**: `cobble-viz-*` are declared in
  `cobble/pyproject.toml` but not installed under `uv run --no-sync`, and the modules have no
  `__main__`; the script imports `main()` directly.
- **viz-callgraph is LINK-only**: CardDemo's online flow is XCTL, so the as-shipped call graph for
  COSGN00C has 3 nodes and 0 edges (`viz/COSGN00C-callgraph.html`). The slide image
  (`viz/COSGN00C-callgraph-xctl.*`) comes from a scratch copy of edges.jsonl with XCTL relabelled
  as LINK — say "XCTL" on the slide.
- **viz-sequence (top) is wrong for XCTL**: shows only COSGN00C → COADM01C (misses COMEN01C) and
  draws a dashed return arrow, but XCTL never returns. Prefer the call graph or dataflow slide for
  the cross-program story.
- **viz-dataflow does not fit CardDemo**: it looks for a commarea → record-write convention from
  another estate and yields 0 flows (`dataflow/viz-dataflow-COACTVWC.json`). `dataflow/dataflow.html`
  is drawn by the capture script from the text query outputs instead; origin rows (LITERAL,
  %CICS-STATE) are omitted from diagram 2 and their children attached to the nearest field.
- **fields-trace follows LINK only**: on COACTVWC it stays in one program (its XCTL target is a
  variable); cross-program flow comes from the fixpoint query's `--across-calls`, which treats XCTL
  as inbound-only.
- **Under-approximation**: trace paths run loop bodies once; the fixpoint query stops at depth /
  hop limits without saying why (`bm7`, `nsv`, `u3v` open beads per `cobble/README.md`).
- **Screens are source-only**: INITIAL text, no run-time values; COTRN0A's instruction line
  renders truncated ("…details from the li").
- **viz HTML is not offline**: callgraph/sequence pages load vis-network (unpkg) and mermaid
  (jsdelivr) from CDNs, unpinned; `graph-webgl.html` and `screens/*.html` are self-contained. Use the
  PNGs in the deck.
- **graph.png is the WebGL page** (`cobble-render-webgl`, sfdp layout precomputed), screenshot by
  headless Chrome with SwiftShader (`capture/screenshot.sh`); the vis-network `graph.html` is no
  longer captured.
