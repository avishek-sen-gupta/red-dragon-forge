# TN3270 Green-Screen Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Serve unmodified CICS programs (CardDemo first) to stock 3270 emulators over TN3270, with every screen-fidelity feature also driven and asserted headlessly.

**Architecture:** One BMS layout model (`bms_copybook_gen`) feeds a protocol-neutral runtime layer: a richer SEND MAP payload, a pure `TerminalScreen`, faithful RECEIVE MAP, and a `RegionDriver` that runs one terminal turn at a time. `cics.tn3270` is an adapter over that layer: telnet negotiation, a 3270 encoder/decoder, a session loop, a CLI. Headless tests and the TN3270 session drive regions through the same `RegionDriver`.

**Tech Stack:** Python 3.13, uv workspace, pytest (+xdist), RedDragon VM, ProLeap bridge, `hlasm_export`, import-linter, pyright, python-fp-lint, s3270 (x3270 suite) for wire e2e.

**Spec:** `docs/superpowers/specs/2026-09-17-tn3270-terminal-design.md`

**Reference implementations:** `docs/superpowers/plans/2026-09-17-tn3270-terminal-reference/` mirrors repo paths (`cicada/bms_copybook_gen/…`, `cicada/cics/{bms,screen,tn3270}/…`). Every file there already passes python-fp-lint (except `wire.py`, excluded by design) and pyright against the real packages, and a throwaway smoke suite exercised parser, attributes, screen merge rules, payload round-trip, drain, address codec, encode→decode, negotiation, session flow and the socket tokenizer. Reference files carry a `.py.ref` suffix so repo hooks do not lint them as live code; "Create from reference" means copy `<path>.py.ref` to `<path>.py` under the repo root, then run the task's tests. The final task deletes the reference directory.

## Decisions refining the spec

These came out of drafting and verifying the reference code; the spec should be updated in Task 18.

1. **Encoder always sends Erase/Write of the whole modelled screen**, with keyboard restore always set. `TerminalScreen.with_input` mirrors operator input into the model, so repainting loses nothing, and Erase/Write returns any 3278/3279 model to its 24x80 default partition.
2. **Terminal types IBM-3278-2…5 and IBM-3279-2…5 (with or without `-E`) are accepted**, because of (1). x3270's default model 4 therefore works.
3. **`SendTextPayload`** is parsed alongside `SendMapPayload`; the session paints SEND TEXT as an unformatted screen.
4. **`BmsField.justify` and `BmsMap.cursloc` are not added**: nothing consumes them.
5. **`BmsMap.elements`** holds every DFHMDF (captions included); `BmsMap.fields` is a derived property returning only labelled ones, so the copybook generator and cobble consumers are unchanged.
6. **`InputEvent` moves to `cics/input_event.py`** (frozen, gains `cursor`), re-exported from `cics.dispatcher`. `cics.builtins` may import it without breaking `builtins-no-dispatcher`.
7. **RegionDriver gains `knows(transid)`**, so the session can reject an unknown typed transid without catching a `KeyError` from the region.
8. **After a task ends with a plain RETURN, the last screen stays up**; the next attention key on it shows a blank unformatted screen for typing a transid (CLEAR does the same).

from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass

from cics.types import DispatchResult
from interpreter.vm.vm_types import VMState


@dataclass(frozen=True)
class FieldWrite:
    name: str
    data: bytes
    pad: bytes = b"\x00"
    right_justify: bool = False


def _placed(write: FieldWrite, length: int) -> bytes:
    clipped = write.data[:length]
    if write.right_justify:
        return clipped.rjust(length, write.pad)[:length]
    return clipped.ljust(length, write.pad)[:length]


def write_fields(
    vm: VMState, region: bytearray, writes: Sequence[FieldWrite]
) -> frozenset[str]:
    missing = set()
    for write in writes:
        layout = vm.data_layout.get(write.name)
        if layout is None:
            missing.add(write.name)
            continue
        offset, length = layout["offset"], layout["length"]
        region[offset : offset + length] = _placed(write, length)
    return frozenset(missing)


def commit_region(vm: VMState, address: int, region: bytearray) -> None:
    vm.region_set(address, region)


def record_result(holder: list[DispatchResult], result: DispatchResult) -> None:
    holder[0] = result

_MODE_OPTIONS = (("MAPONLY", SendMode.MAPONLY), ("DATAONLY", SendMode.DATAONLY))


def _names_arg(args: Sequence[TypedValue], index: int) -> tuple[str, ...]:
    value = args[index].value if len(args) > index else ()
    return tuple(str(v) for v in value) if isinstance(value, list) else ()


def _cursor_arg(args: Sequence[TypedValue], index: int) -> int:
    text = str(args[index].value).strip() if len(args) > index else ""
    return int(text) if text.lstrip("-").isdigit() else -1


def _send_mode(flags: frozenset[str]) -> SendMode:
    return next((mode for option, mode in _MODE_OPTIONS if option in flags), SendMode.FULL)


def _halfword(vm: VMState, region: bytearray, name: str) -> int:
    raw = read_ws_field(vm, region, name)
    return struct.unpack(">h", raw)[0] if len(raw) == 2 else 0


def _byte(vm: VMState, region: bytearray, name: str) -> int:
    raw = read_ws_field(vm, region, name)
    return raw[0] if raw else 0


def _send_cursor(vm: VMState, region: bytearray, bases: Sequence[str], flags: frozenset[str], offset: int) -> CursorPosition:
    """CURSOR(n) is an offset; a bare CURSOR takes the first field whose <f>L is -1."""
    marked = tuple(b for b in bases if _halfword(vm, region, b + "L") == -1)
    symbolic = SymbolicCursor(marked[0]) if marked else NO_CURSOR
    explicit = Cursor(offset) if offset >= 0 else symbolic
    return explicit if "CURSOR" in flags else NO_CURSOR


def _symbolic_values(vm: VMState, region: bytearray, bases: Sequence[str]) -> Mapping[str, str]:
    raw = {b: read_ws_field(vm, region, b + "O") for b in bases}
    return {b: data.decode("cp037", errors="replace").rstrip() for b, data in raw.items() if data}


def _overrides(vm: VMState, region: bytearray, bases: Sequence[str]) -> Mapping[str, FieldAttributes]:
    attrs = {b: FieldAttributes(_byte(vm, region, b + "A"), _byte(vm, region, b + "C"), _byte(vm, region, b + "H")) for b in bases}
    return {b: a for b, a in attrs.items() if a.overrides}


def _send_map_payload(args: Sequence[TypedValue], vm: VMState) -> SendMapPayload:
    bases = _names_arg(args, 1)
    flags = frozenset(_names_arg(args, 3))
    region = ws_region(vm).data
    mode = _send_mode(flags)
    symbolic = mode is not SendMode.MAPONLY
    return SendMapPayload(
        map=_map_name(args, 0),
        mapset=_map_name(args, 2),
        mode=mode,
        erase="ERASE" in flags,
        alarm="ALARM" in flags,
        frset="FRSET" in flags,
        freekb="FREEKB" in flags,
        cursor=_send_cursor(vm, region, bases, flags, _cursor_arg(args, 4)),
        fields=_symbolic_values(vm, region, bases) if symbolic else {},
        attrs=_overrides(vm, region, bases) if symbolic else {},
    )

import os

import pytest

from cics.tn3270.config import load_config
from cics.tn3270.region import build_region

from tests.covers import NotLanguageFeature, covers
from tests.integration.cobol_helpers import bridge_jar  # noqa: F401

pytestmark = [pytest.mark.carddemo_e2e, pytest.mark.tn3270_e2e]

_CONFIG = Path(__file__).parents[3] / "config" / "carddemo-tn3270.toml"


class _S3270:
    def __init__(self, port: int):
        if shutil.which("s3270") is None:
            pytest.fail("s3270 is not installed; install the x3270 suite (brew install x3270)")
        self.proc = subprocess.Popen(["s3270", "-model", "2"], stdin=subprocess.PIPE, stdout=subprocess.PIPE, text=True)
        self.run(f"Connect(127.0.0.1:{port})")
        self.run("Wait(10,InputField)")

    def run(self, command: str) -> list[str]:
        self.proc.stdin.write(command + "\n")
        self.proc.stdin.flush()
        lines = []
        while (line := self.proc.stdout.readline().rstrip("\n")) not in ("ok", "error"):
            lines.append(line)
        assert line == "ok", f"{command} failed: {lines}"
        return [l[len("data: "):] for l in lines if l.startswith("data: ")]

    def screen(self) -> str:
        return "\n".join(self.run("Ascii()"))

    def enter(self, key: str = "Enter") -> str:
        self.run(key)
        self.run("Wait(30,InputField)")
        return self.screen()


@covers(NotLanguageFeature.INFRASTRUCTURE)
def test_signon_menu_account_view_and_back(tmp_path, bridge_jar, monkeypatch):

    config = load_config(_CONFIG)
    served = build_region(config, bridge_jar, tmp_path)
    server = bind("127.0.0.1", 0)
    session = partial(run_session, driver=served.driver, catalog=served.catalog, initial_transid=config.initial_transid)
    threading.Thread(target=serve_forever, args=(server, session), daemon=True).start()
    account = (Path(os.environ["CARDDEMO_HOME"]) / "data/EBCDIC/AWS.M2.CARDDEMO.CARDXREF.PS").read_bytes()[25:36].decode("cp037")

    terminal = _S3270(server.getsockname()[1])
    assert "User ID" in terminal.screen()
    terminal.run('String("USER0001")')
    terminal.run("Tab")
    terminal.run('String("PASSWORD")')
    assert "Main Menu" in terminal.enter()
    terminal.run('String("01")')
    assert "View Account" in terminal.enter()
    terminal.run(f'String("{account}")')
    shown = terminal.enter()
    assert account in shown
    assert "Main Menu" in terminal.enter("PF(3)")
    terminal.run("Quit")
